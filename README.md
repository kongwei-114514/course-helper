# Course Helper

清华选课辅助浏览器插件 demo，用于把培养方案、开课信息、课程评价、下学期推荐课和选课志愿人数统计放在同一个面板里，辅助规划下学期选课。

## 功能

- √培养方案解析与完成情况展示
- √选课社区课程评价同步与教师维度评价查看
- √下学期推荐课程抓取
- √开课信息抓取与课程搜索
- √课表规划、冲突检测、时间待定课程展示
- √已选课程志愿填报情况管理
- √选课人数和一/二/三志愿人数统计展示
- √基于容量和当前志愿人数的粗略中签概率估算
- ×选课界面和插件信息同步（目前插件只能规划时间，不能在插件选课）
- ×还没有增加切换学期功能，只能看到最新的选课内容

## 安装 Demo

1. 下载或 clone 本仓库。
2. 打开 Chrome / Edge 的扩展管理页：`chrome://extensions`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本项目根目录，也就是包含 `manifest.json` 的目录。
6. 点击扩展图标打开 Course Helper dashboard。

## 使用说明

首次使用通常需要先登录清华相关系统：

- 培养方案：点击“更新培养方案”
- 课程评价：点击“更新选课评价”
- 下学期推荐课：点击“下学期推荐课”
- 开课信息：点击“抓取开课信息”
- 选课人数统计：点击“刷新选课人数”

选课规划页中可以把课程加入课表，查看时间冲突、教师评价、容量、志愿人数和预计中签概率。非培养方案内课程默认按任选处理；体育课会单独归入体育志愿组。

## 数据与隐私

本插件是本地 demo，数据默认存储在浏览器的 `chrome.storage.local` 中，不会上传到本仓库或自建服务器。

插件会访问以下数据来源：

- 清华网络学堂 / 教务相关页面，用于读取培养方案和跳转认证
- 清华选课系统，用于读取开课信息、推荐课、选课人数统计
- 选课社区接口，用于读取课程评价

## 项目结构

```text
.
├── manifest.json              # Chrome extension manifest
├── background.js              # 后台抓取、认证跳转与消息处理
├── content.js                 # 登录页辅助注入
├── dashboard.html             # 主面板页面
└── scripts/
    ├── dashboard.js           # 培养方案 dashboard
    ├── schedule-planner.js    # 选课规划器
    ├── fetcher-ui.js          # 抓取按钮与进度提示
    ├── parser.js              # 培养方案解析
    ├── analyser.js            # 培养方案分析
    └── exporter.js            # 数据导出
```
